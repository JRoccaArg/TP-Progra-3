## Ejecutar

Requiere Python 3.10. Abre una terminal en la carpeta del proyecto y ejecuta:

```
python tp_greedy_rocca.py
```

Esto corre los tres mapas y guarda los logs en la carpeta `salidas`.

### Con el simulador

1. Instala el simulador (solo la primera vez):
   ```
   cd UadeRobotLab\04Simuladores\UnitreeMujocoOficial
   setup_windows.bat
   ```
2. Ábrelo con `abrir_g1_sim.bat` y deja abierta la ventana de MuJoCo.
3. En otra terminal, en la carpeta del proyecto, ejecuta el mapa que quieras (1, 2 o 3):
   ```
   python tp_greedy_rocca.py robot 1
   ```
   Pide ENTER para empezar.
